# CLAUDE.md
`tag-buddy` è un tool personale di Francesco. **Prima di lavorarci invoca la skill `development:index`**: smista sulle convenzioni che si applicano a questo repo — interfaccia della CLI, metodo di lavoro sul progetto, test, standard dei tool personali — e indica la nota di standard che le governa.

I test si lanciano con `vendor/bin/phpunit`. Per come si tratta un test rosso vale `development:code-quality`.

`DECISIONS.md` si legge prima di modificare il codice. Dopo una modifica controlla se quello che hai fatto compare fra i gesti registrati: se sì, segnalalo a Francesco e aspetta.
